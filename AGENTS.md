# Repository rules

- Keep `skills/ai-4u/SKILL.md` concise and platform-neutral.
- Keep platform adapters semantically aligned with the core skill.
- Do not claim platform support without current official documentation.
- Do not add reasoning-mode control; users manage it in their chosen platform.
- Validate the skill with the official `quick_validate.py` before release.
- Preserve the Goal, Context pointers, Constraints, and Done when execution gate.
